Drop your meeting / 1:1 session screenshots in this folder.

Name them exactly:
  meeting-1.jpg
  meeting-2.jpg
  meeting-3.jpg
  meeting-4.jpg
  meeting-5.jpg
  meeting-6.jpg

They will automatically appear in the scrolling marquee on the home page
(the "helping beginners start & grow in freelancing" section).

Tips:
- Roughly 16:10 landscape images look best (e.g. 1280x800).
- .jpg is expected. To use .png, update the src filenames in index.html.
- Until a file exists, a soft placeholder card is shown in its place.
- Want more than 6? Duplicate a <figure class="meeting-card">...</figure>
  in BOTH "Set A" and "Set B" inside index.html so the loop stays seamless.
